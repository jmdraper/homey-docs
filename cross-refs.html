1 Connect Claude ▶
Install mcp-remote on each machine that runs Claude Desktop (one-time):
npm install -g mcp-remote
On macOS you may need sudo npm install -g mcp-remote if you get a permissions error.
Enter your Homey’s local IP address to generate the config snippet:
Find it in Homey → Settings → General → Local IP address. Your machine running Claude Desktop must be on the same local network.
Add to Claude Desktop config and restart Claude Desktop: macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
Windows: %APPDATA%\\Claude\\claude_desktop_config.json
(enter your Homey IP above to generate config)
