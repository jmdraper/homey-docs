Network access

Comma-separated. IP addresses, localhost and .local names are always allowed — this is only needed when you reach Homey by a domain name, such as through a reverse proxy or Tailscale MagicDNS. Requests from other hostnames are refused, which is what stops a website you visit from reaching Homey through your browser.

Nothing has been refused.

Flow editing

Off by default. While off, every editing tool refuses and the MCP server stays read-only. Turning this on lets a connected assistant change card arguments, add and remove cards, rewire connections, rename flows and enable or disable them. It cannot delete flows — that stays a manual action in the Homey app, because a recreated flow gets a new id and anything that triggers it would break.

The app's own token can read flows but not change them, so editing needs a token you create yourself. In the Homey web app go to Settings → API Keys, create a key with flow write access, and paste it here. Leaving this empty keeps everything read-only no matter what the switch above says.

A copy of a flow is saved before every edit, so a change can be undone with the revert tool. Editing tends to be iterative, so keeping several matters — the copy you want back is usually not the most recent one. Consider installing Flow Version History as well: it records changes from any source, including your own edits in the Homey app.
